# sync_doc_stats

> Источник: `scripts/sync_doc_stats.py`

## Назначение

Держит захардкоженные числа, разбросанные по `CLAUDE.md` и `Readme.md`, в соответствии с реальностью. Спецификация растёт при каждой синхронизации с upstream, поэтому любое число, вписанное вручную — количество строк спеки, число секций, записей метаданных, FAISS-векторов, ключевых слов, рёбер графа зависимостей — дрейфует и тихо становится неверным. Скрипт пересчитывает каждое такое число из `FPF-Spec.md` + `sections/metadata.json` и перезаписывает оба документа на месте, так что цифры не могут устареть дольше одного ребилда. Запускается как шаг 8 в `scripts/rebuild_all.sh`, а его режим `--check` служит ещё и гейтом против дрейфа. Только стандартная библиотека — `uv` и FAISS-индекс не нужны.

Количество FAISS-векторов **выводится**, а не замеряется: оно равно числу записей метаданных, у которых есть поле `file` (записи без файла секции, например preface/ToC, не индексируются). Чтобы его посчитать, индекс эмбеддингов существовать не обязан.

## Интерфейс

| Функция | Сигнатура | Что делает |
|---------|-----------|-----------|
| `compute_stats` | `() -> dict` | Читает `FPF-Spec.md` + `sections/metadata.json` и дерево `sections/`; возвращает словарь всех выводимых чисел (строки/MB/токены спеки, число файлов секций, контент-директории, записи, ключевые слова, запросы, рёбра, векторы, проценты, размер FAISS) |
| `sp` | `(n: int) -> str` | Группирует цифры тонким пробелом — `12345` → `'12 345'` (русская запись, используется в `Readme.md`) |
| `en` | `(n: int) -> str` | Группирует цифры запятой — английский разделитель тысяч |
| `round_to` | `(n: int, base: int) -> int` | Округляет `n` до ближайшего кратного `base` (для приблизительных `~N` цифр) |
| `plural_ru` | `(n: int, one: str, few: str, many: str) -> str` | Подбирает правильную форму русского существительного по числу (учитывает исключение 11–14 и правило по `%10`) |
| `build_rules` | `(s: dict) -> dict[str, list[tuple[re.Pattern, str]]]` | Строит для каждого файла список правил `(regex, замена)` из словаря статистики; ключи — `"CLAUDE.md"` и `"Readme.md"` |
| `process` | `(check: bool) -> int` | Применяет или проверяет все правила по обоим файлам; возвращает код выхода (`0` — ок / дрейф устранён, `1` — найден дрейф в режиме проверки) |
| `main` | `() -> None` | Парсит `--check` и вызывает `sys.exit(process(...))` |

## Алгоритм

1. **`compute_stats`** читает размер спеки в байтах и число строк (`count(b"\n")`, как `wc -l`), загружает `sections/metadata.json` и суммирует `keywords`, `queries` и рёбра `dependencies` по всем записям. Считает `.md`-файлы секций (исключая `_index.md`, `_xref.md`, директории `routes/` и `embeddings/` и файлы верхнего уровня), контент-директории и суммарный размер секций в байтах. `vectors` = записи с полем `file`; `no_file` = остальные; `faiss_kb`, `vec_pct` и цифры MB/токенов спеки выводятся арифметически.
2. **`build_rules`** превращает эти числа в правила замены. Каждое правило — пара `(regex, фрагмент)`: regex матчит текущую строку, оставляя число «свободным» (чтобы найти фрагмент независимо от устаревшего значения), а фрагмент — исправленный текст. Русские фрагменты используют хелперы `plural_ru` (`secs`, `vec_nom`, `files_ru`, …) для согласования существительных; приблизительные цифры — `round_to`.
3. **`process`** загружает каждый файл и прогоняет все правила через `pat.sub(..., count=1)`. Если regex правила не совпал, фиксируется заметка о дрейфе (документ, вероятно, правили руками и сбили ожидаемую форму). В режиме применения файл перезаписывается и печатается, что изменилось; в `--check` фиксируется «stale numbers» без записи.
4. Если `--check` нашёл дрейф, `process` печатает отчёт и возвращает `1` (гейт роняет сборку); иначе печатает `up to date ✓`. В режиме применения печатает однострочную сводку синхронизированных цифр.

## Зависимости

**Импорты:** `argparse`, `json`, `re`, `sys`, `pathlib.Path` — только стандартная библиотека.

**Читает:** `FPF-Spec.md`, `sections/metadata.json`, дерево `sections/`.
**Пишет / проверяет:** `CLAUDE.md`, `Readme.md`.

**Где используется:** `scripts/rebuild_all.sh` (шаг 8, режим применения). Режим `--check` задуман как гейт против дрейфа в CI/пред-коммите.
