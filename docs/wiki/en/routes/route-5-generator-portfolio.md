# Route 5: Generator Portfolio

> Source: `sections/routes/route-5-generator-portfolio.md`

## Summary

Route 5 is triggered when the user asks "what's the state of the art in X?", "what approaches exist for Y?", or "I need a reusable scaffold to survey a field / a portfolio of approaches". It loads an ordered chain of sections so the Reasoner can produce an overview of schools/approaches, a comparison table, a reusable search scaffold, and a shortlist of what to pursue. Like all ten entry routes, it is generated by `scripts/build_routes.py` from a static `ROUTES` table and resolved against `sections/metadata.json` for titles and file paths.

## Key Decisions

- **Burden mapping:** route slug `generator-portfolio` (id `5`); user-says trigger is "What's the state of the art in X? / need a reusable search scaffold / portfolio of approaches".
- **Chain length:** 7 sections in full load, 3 marked core.
- **Core sections** (minimum load for simple queries):
  - `A.0` — Onboarding Glossary (NQD & E/E-LOG)
  - `G.0` — CG-Spec — Frame Standard & Comparability Governance
  - `G.1` — CG-Frame-Ready Generator
- **Full chain** adds (for complex queries):
  - `G.2` — SoTA Harvester & Synthesis
  - `G.5` — Multi-Method Dispatcher & MethodFamily Registry
  - `B.5.2.1` — Creative Abduction with NQD
  - `C.17` — Creativity-CHR — Characterising Generative Novelty & Value
- **Loading strategy:** minimum load is the first 3 core sections; full load is all 7 in chain order; if stagnation is detected, the Retriever falls back to `_xref.md` cross-references.

## Status

Active. Generated by `scripts/build_routes.py` (the `id: 5`, `slug: generator-portfolio` entry in `ROUTES`) and used by the agent team for the `generator_portfolio` coordination burden. The Reasoner emits the route's plain-language deliverable: approaches list → comparison table → reusable scaffold → shortlist. Section IDs in the chain (`A.0`, `G.0`, `G.1`, `G.2`, `G.5`, `B.5.2.1`, `C.17`) are kept in sync with the spec via `sections/metadata.json`; regenerating routes after an upstream sync re-resolves their titles and file paths.
