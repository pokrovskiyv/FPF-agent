# Route 6: Rewrite Explanation

> Source: `sections/routes/route-6-rewrite-explanation.md`

## Summary

Triggered when the user says "rewrite without changing the meaning", "explain this for a different audience", or "compare these two versions for faithfulness". The output is the rewritten text plus notes on what was preserved and what was changed, plus a faithfulness profile — so the rewrite isn't a silent translation that quietly drops or distorts meaning. This is the shortest Tier 1 route (5 sections total, 3 core). The route file is generated by `scripts/build_routes.py` from the `ROUTES[5]` entry, which fills each pattern's title and file path from `sections/metadata.json`.

## Key Decisions

- **Chain length:** 5 sections in full load (the shortest Tier 1 route), 3 of them core.
- **Core sections:** `A.6.3.CR` (conservative retextualization — entity-of-concern-preserving), `A.6.3.RT` (representation-scheme transition, EntityOfConcern-preserving), `E.17.EFP` (ExplanationFaithfulnessProfile — explanation-use discipline).
- **Full chain adds:** `E.17.ID.CR` (ComparativeReviewUnit — bounded comparison over comparative review units) and `E.17.AUD.LHR` (PublicationUnit Stability Discipline and Local Head Restoration).
- **`A.6.3.CR` resolution:** it is listed first in the chain (and is core) and resolves to `sections/06-cluster-aiva-signature-stack-boundary-discipline-a6/10-a63cr-a63cr-conservativeretextualization-entityofconcern-preservin.md`.

## Status

Active. Used for the `rewrite_explanation` burden. Reasoner output template: "Rewritten text → What was preserved → What was changed (with rationale)". The route file is regenerated by `python3 scripts/build_routes.py` (part of `./scripts/rebuild_all.sh`) whenever metadata changes — the chain and pattern references stay in sync with the source automatically.

## Loading Strategy

- **Minimum load** (simple query): the first 3 core sections.
- **Full load** (complex query): all 5 sections in the chain.
- **On stagnation:** check the relevant `_xref.md` for cross-references.
