# First Principles Framework (FPF) - Core Conceptual Specification

This directory contains the root entry of the FPF specification corpus — a standards-style pattern language for turning difficult engineering, research, management, and mixed human/AI work into explicit, reviewable, improvable reasoning. The single preamble file here establishes authorship, version, and the overall purpose of the specification before the Table of Contents and main pattern bodies begin.

- [Preamble](00-preamble.md) — The opening statement of purpose, authorship, and status for the entire FPF specification.
