# First Principles Framework (FPF) Readme

- [Decide Whether FPF Fits](01-decide-whether-fpf-fits.md) — Helps you judge whether your project is complex enough to need this framework, and who it is designed for.
- [Practical-Use Cards](02-practical-use-cards.md) — Fifteen quick-start cards that help you pick the right first move for the question your project faces right now.

- [What FPF Is](04-what-fpf-is.md) — Explains what the framework does in plain terms: keeps meanings stable across teams, documents, and time.
- [What FPF Is Not](05-what-fpf-is-not.md) — Lists what to stop expecting: no checklist bureaucracy, no domain expertise replacement, no demand to read everything first.
- [How to Use This Repository](06-how-to-use-this-repository.md) — Gives a starting prompt and reading strategy for using the spec with an AI assistant or on your own.
- [Citation](07-citation.md) — Provides the correct reference to cite if you use this framework in your work.
