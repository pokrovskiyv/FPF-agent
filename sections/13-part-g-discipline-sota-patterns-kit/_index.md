# Part G – Discipline SoTA Patterns Kit

- [G.Core - Part G Core Invariants](01-gcore-part-g-core-invariants.md) — Collects the rules shared across all state-of-the-art patterns so each individual pattern can cite rather than repeat them.
- [G.0 - Frame Standard and Comparability Governance — CG‑Spec (G.0)](02-g0-g0-frame-standard-and-comparability-governance-cgspec.md) — Fixes, up front, which comparisons and aggregations are legally meaningful in a given frame so downstream work cannot invent its own hidden rules.
- [G.1 - CG‑Frame‑Ready Generator (G.1)](03-g1-g1-cgframeready-generator.md) — Provides a six-card scaffold for building a reusable, auditable generator that can be cited, versioned, and refreshed without rebuilding from scratch each time.
- [G.2 - SoTA Harvester & Synthesis (G.2)](04-g2-g2-sota-harvester-synthesis.md) — Guides teams through discovering and synthesising competing research traditions into a citable, context-aware pack before any measurement or selection work begins.
- [G.3 - CHR Authoring for a CG‑Frame: Characteristics, Scales, Levels, Coordinates (G.3)](05-g3-g3-chr-authoring-for-a-cgframe-characteristics-scales-levels.md) — Publishes the measurable properties, scales, and reference points for a frame so that all downstream comparisons use legally admissible arithmetic.
- [G.4 - CAL Authoring for a CG-Frame: Operators, Acceptance Clauses, Evidence Wiring (G.4)](06-g4-g4-cal-authoring-for-a-cg-frame-operators-acceptance-clauses.md) — Defines what operations are permitted on measured values, what counts as an acceptable result, and how evidence must be wired before any selection runs.
- [G.5 - Multi‑Method Dispatcher and MethodFamily Registry (G.5)](07-g5-g5-multimethod-dispatcher-and-methodfamily-registry.md) — Keeps rival approaches in a governed registry and returns honest shortlists instead of forcing a single hidden winner when several methods are legitimately valid.
- [G.6 - Evidence Graph and Provenance Ledger: Citable Evidence-Provenance Paths (G.6)](08-g6-g6-evidence-graph-and-provenance-ledger-citable-evidence-pro.md) — Makes every claim traceable to a stable, replayable path through sources, checks, and time windows so auditors and downstream users can verify rather than guess.
- [G.7 - Cross‑Tradition Bridge Calibration Kit (BridgeMatrix → BridgeCards + BCT/Sentinels) (G.7)](09-g7-g7-crosstradition-bridge-calibration-kit-bridgematrix-bridge.md) — Turns rough cross-field correspondences into explicit, calibrated bridge cards with stated losses, so that translation between research traditions is checkable rather than informal.
- [G.8 - SoS‑LOG Bundles & Maturity Ladders (G.8)](10-g8-g8-soslog-bundles-maturity-ladders.md) — Packages decision rules and maturity stages into a citable, selector-ready bundle so that admissibility decisions stay auditable and do not get buried in prose.
- [G.9 — Parity and Benchmark Harness (G.9)](11-g9-g9-parity-and-benchmark-harness.md) — Ensures that comparisons between rival approaches are run under the same declared baseline, freshness window, and evidence pins so results can actually be trusted.
- [G.10 - SoTA Pack Shipping (G.10)](12-g10-g10-sota-pack-shipping.md) — Defines the single normative boundary for releasing a research pack so consumers receive stable, citable artefacts without the shipping step silently rewriting the rules.
- [G.11 - Telemetry-Driven Refresh and Decay Orchestrator (G.11)](13-g11-g11-telemetry-driven-refresh-and-decay-orchestrator.md) — Detects which parts of a shipped pack have become stale and plans targeted, scoped updates instead of forcing a full rebuild every time something changes.
- [G.12 — DHC Dashboards (Discipline‑Health time‑series; admissible telemetry; generation‑first) (G.12)](14-g12-g12-dhc-dashboards-disciplinehealth-timeseries-admissible-te.md) — Produces discipline-health dashboards whose rows are evidence-citable and whose telemetry is wired for targeted refresh rather than silent drift.
- [G.13 - External Interop Hooks for SoTA Discipline Packs (conceptual) (G.13)](15-g13-g13-external-interop-hooks-for-sota-discipline-packs-concept.md) — Provides conceptual hooks for wiring external indexes and repositories into the research pipeline without letting them quietly act as a competing source of rules.
